# Vishnu Gajavada Portfolio

Static HTML, CSS, and JavaScript portfolio. All site assets are kept together in the repository root.

## Publish with GitHub Pages

1. Push the repository contents to GitHub, including `index.html`, `styles.css`, `enhancements.css`, `screenshots.css`, `script.js`, the `assets/` folder, and `resume.pdf`.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. Open the Pages URL after deployment. The live public repository cards require a network connection to GitHub's API.

The `.nojekyll` file keeps GitHub Pages from applying Jekyll processing to this plain static site.
